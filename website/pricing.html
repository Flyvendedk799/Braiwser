Pricing

Free stays useful offline. Pro features are unlocked by an offline-verified licence key. There is no online checkout yet.

Free

Browse, annotate, audit, record journeys, export Markdown, copy agent prompts. AI works with your own subscription or API key, or falls back to a clearly labelled local summary. Works fully offline.

Pro

Agent hand-off templates, Playwright export, client packs, HTML reports, project bundles, AI polish, issue drafts. Released builds require a Pro licence key for these; builds run from source are unlocked and labelled as development builds.

Team — not available yet

Team workspaces today are local records on one machine: invitations are not sent, comments are not shared, and there is no hosted sync, single sign-on, SCIM or seat billing. We will announce Team here when those exist.

Licence keys are signed tokens that Braiwser verifies offline against a public key. The app has no payment flow; keys are issued by the maintainers. Activate a key under Settings.
