Privacy model

Braiwser is local-first. Projects, notes, journeys, and API keys stay on your machine by default.

No account required

Core review works fully offline. Cloud sync and team features are opt-in.

Analytics

Anonymous product events are off until you enable them in Settings. Diagnostics bundles are user-triggered.

AI calls

Only leave the machine when you run an AI task with your own subscription or API key.
