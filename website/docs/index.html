Documentation

Install, try the sample page, connect AI credentials if you want, hand off to an agent, verify the fix, export Playwright, and understand the privacy model.

Install

Download a release build, or npm install && npm start from the repo. Requires Node 18+ for development.

AI credentials

Claude / Codex subscription (CLI already signed in), or Anthropic / OpenAI API keys in Settings. No key → local synthesis.

Agent hand-off

Copy prompt or Hand off. If claude, cursor-agent, or codex is on PATH, pick it from the preset row. Templates: Fix UI, Accessibility, Responsive, Regression.

Verify

After a hand-off, Verify session re-runs the page audit and the selected journey, then stores a before/after (audit delta, pass/fail, screenshots) on the session.

Playwright export

Record a journey → export a runnable spec. Drop it under tests/braiwser or use Integrations → CI starter.

Client packs

Agency persona: set studio name, mark notes client-facing, export HTML report or client pack Markdown.

Sync & team

Experimental. Sign-in under Settings queues encrypted snapshots locally — there is no hosted sync endpoint yet.
