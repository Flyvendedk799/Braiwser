Documentation

Install, connect AI credentials, hand off to an agent, export Playwright, and understand the privacy model.

Install

Download a release build, or npm install && npm start from the repo. Requires Node 18+ for development.

AI credentials

Claude / Codex subscription (CLI already signed in), or Anthropic / OpenAI API keys in Settings. No key → local synthesis.

Agent hand-off

Copy prompt or Hand off. Templates: Fix UI, Accessibility, Responsive, Regression. Configure agentCommand with {promptPath}.

Playwright export

Record a journey → export a runnable spec. Drop it under tests/braiwser or use Integrations → CI starter.

Client packs

Agency persona: set studio name, mark notes client-facing, export HTML report or client pack Markdown.

Sync & team

Optional. Sign in under Settings to queue encrypted project snapshots. Team workspaces add comments and invites.
