Braiwser
Annotation-first inspector browser

Review any web project,
edit it live, ship it to your agent.

Open a local project or any URL. Point at what needs work and leave notes, restyle and rewrite it in place, rearrange the layout, audit accessibility, record journeys as tests — then export the whole review as a doc, an agent prompt, a Playwright spec, or the component itself.

1
Open anythingHit File or Folder for a local project, or type any URL. Tabs, history and bookmarks all work.
⌖
Inspect ⌘⇧EHover to highlight, click to capture an element — selector, classes, text and styles — and write a note against it.
✎
Draw ⌘⇧DCircle any area freehand and attach a note to the region, for the things a selector cannot express.
✐
Edit ⌘⇧TType straight into the page, and change font, size, colour, spacing and opacity in the Style panel. Every change becomes a note with the exact CSS.
✥
Rearrange ⌘⇧MDrag elements into any container, pull the handles to resize, or re-lay-out a container as a row, column or grid.
☰
Sections & LayersThe left panel is the page: a named tree of its sections, and the stacking order of whatever you have selected. Click to jump, drag to reorder, the eye hides.
✓
Audit ⌘⇧UA local contrast / alt-text / label / tap-target scan. Promote any finding straight into a note.
▭
Every breakpointSwitch the device viewport to review mobile, tablet and desktop — notes remember the size they were taken at.
↻
Record & replay ⌘⇧JCapture a real journey and play it back. Assertions turn it into a smoke test, and it exports as a video, a PDF, or a Playwright spec.
→
Hand it over ⌘⇧HExport the session as Markdown, an agent prompt or JSON, lift a single component off the page as a standalone file, or run your coding agent on the review right here.
