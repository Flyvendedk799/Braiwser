Chrome AI OS
Annotation-first inspector browser

Review any web project,
edit it live, ship it to AI.

Open a local project or any URL. Point at what needs work and leave notes, restyle and rewrite it in place, rearrange the layout — then export the whole thing as a review doc, an agent prompt, or the component itself.

1
Open anythingHit File or Folder for a local project, or type any URL. Tabs, history and bookmarks all work.
⌖
Inspect ⌘1Hover to highlight, click to capture an element — selector, classes, text and styles — and write a note against it.
✎
Draw ⌘2Circle any area freehand and attach a note to the region, for the things a selector cannot express.
✐
Edit ⌘3Type straight into the page, and change font, size, colour, spacing and opacity in the Style panel. Every change becomes a note with the exact CSS.
✥
Rearrange ⌘4Drag elements to move them into any container, pull the handles to resize, or re-lay-out a container as a row, column or grid.
☰
Sections & LayersThe left panel is the page: a named tree of its sections, and the stacking order of whatever you have selected. Click to jump, drag to reorder, the eye hides.
↻
Record & replayCapture a real journey and play it back — smoothly, as it happened. Export it as a video, a PDF, or a written step-by-step for a bug report.
→
Hand it overExport the session as Markdown, a ready-to-run agent prompt, or JSON — or lift a single component off the page as a standalone file. Press ? any time for the shortcuts.
